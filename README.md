# Agenda com Login

Sistema de agenda com autenticação de usuários, desenvolvido em equipe como projeto acadêmico do curso de Tecnologia em Análise e Desenvolvimento de Sistemas (IFSP, Campus Campinas).

## Sobre o projeto

Este projeto foi desenvolvido por três pessoas, com divisão de tarefas e trabalho colaborativo. O objetivo é permitir que cada usuário tenha sua própria conta e gerencie seus compromissos de forma simples e organizada.

## Funcionalidades

- Cadastro e login de usuários
- criar, editar e excluir compromissos
- visualizar compromissos por data
- lembretes, categorias, busca.

## Tecnologias utilizadas

- [Linguagem: C# ou Python
- Banco de dados: MySQL
